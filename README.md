# For My Brother — Birthday Surprise Website

A simple but special birthday webpage built with HTML, CSS, and JavaScript.

## What it includes
- Opening surprise screen
- Birthday countdown
- Memory/photo gallery
- Funny “brother things” section
- Heartfelt letter
- Awards section
- Mini quiz game
- Gift box reveal with confetti

## How to view locally
1. Open `index.html` in a browser.
2. Or serve it with a local web server if you prefer:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customize it
Edit the following in `script.js`:
- `BROTHER_NAME` if you want a specific name
- `BIRTHDAY_DATE` to match the actual birthday date
- `quizData` with your own personal questions

## Publish it
If you want to deploy to GitHub Pages:
1. Push this folder to a repository.
2. Go to GitHub → Settings → Pages.
3. Choose `Deploy from a branch` and use the `main` branch.
4. Save and wait for the URL.

## Optional design tweak
You can replace the remote images with real family photos to make it even more personal.

Enjoy the birthday surprise! ❤️
